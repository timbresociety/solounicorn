# Exec plans

Exec plans are the durable handoff between humans and automated coding agents for multi-step work.

- `active/` contains work currently being executed.
- `completed/` contains finished plans with validation evidence.
- Copy `TEMPLATE.md` when a task crosses architecture layers, needs multiple agents, or has multiple acceptance checkpoints.

Keep plans about execution. Do not duplicate product or design canon into them; link the authority.
