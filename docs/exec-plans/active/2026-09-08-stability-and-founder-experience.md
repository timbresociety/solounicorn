## Diagnosed and repaired

- Old accepted events triggered repeated full-save writes; writes are now bounded at five seconds and on backgrounding. IndexedDB reuses one connection, reports errors, handles blocked opens and aborts, and verifies restored state checksums.
- Paused runtime advanced no economic state but notified React repeatedly; it now returns the identical snapshot without notifying. Explicit pause/resume is replayable and paused work rejects clearly.
- Pointer cancellation could commit Marketing; cancellation now resets the gesture, and successful swipes reset the next card. Window blur/resize cancels local gesture state.
- Empty Product, Monetization, Retention and Expansion rooms could falsely advertise completed or waiting work. Clear empty states and a persistent next-work/fast-forward exit replace those dead ends.
- Finance hid principal repayment after the offer left its queue. Financing controls now remain available after the offer decision.
- Retention's first resolved threat could cover unresolved targets. The completion overlay waits for the remaining targets.
- Missing unicorn continuation and abandoned-run handling are explicit terminal-path concerns; unicorn now has a continuation action and cannot overwrite cash failure.
- Pricing quoted a hard-coded dollar value and static bands. Quote/bands now use the same existing profile values as the resolver.
- Repeated Expansion commits reject instead of booking again. Unaffordable Marketing purchases reject without consuming the opportunity, allowing ignore instead.
- Offline cache no longer returns HTML as JavaScript; updates wait for session boundaries, and development does not install the worker.
- Invalid paused replay schedules fail explicitly instead of spinning forever.
