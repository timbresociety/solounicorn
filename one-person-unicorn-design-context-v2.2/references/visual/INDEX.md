# Visual reference index

Founder-supplied references outrank external inspiration. Generated examples demonstrate interpretation and can be rejected or superseded without changing the design system.

## Founder / canonical references

### `founder/structure-monogram-primary.png`
**Authority:** canonical Structure monogram geometry.  
**Use for:** silhouette, curve family, negative space, app icon geometry.  
**Do not infer:** current magenta color is not a universal product color requirement; do not redraw the geometry loosely.

### `founder/structure-spark-monogram-family.png`
**Authority:** canonical relationship between Structure and Spark monograms.  
**Use for:** dual-monogram family, curve grammar, pattern relationships.  
**Do not infer:** random sparkle iconography is not allowed; only the proprietary Spark form is canonical.

### `founder/pastel-ethereal-environment.png`
**Authority:** canonical SKY / Pastel Ethereal atmosphere.  
**Use for:** monumental scale, reflective water, pale cyan/lavender/blush sky, distant tiny human scale, serene depth, editorial brand art.  
**Do not infer:** operational gameplay UI should not become a pastel illustration.

### `founder/rarity-texture-charcoal-stone.png`
**Authority:** texture/surface reference only.  
**Semantic example:** raw, dormant, unrefined starting state.  
**Do not infer:** bust anatomy, subject matter, pose, lighting composition or a universal lowest-tier material.

### `founder/rarity-texture-shiny-gold.png`
**Authority:** texture/surface reference only.  
**Semantic example:** refined, valuable, intentional middle state.  
**Do not infer:** gold is the universal premium material or is required for standard UI icons.

### `founder/rarity-texture-translucent-liquid-glass.png`
**Authority:** texture/surface reference only.  
**Semantic example:** clarified, lucid, purified higher state.  
**Do not infer:** glass is required in every progression or on standard UI.

### `founder/rarity-progression-enlightenment-example.png`
**Authority:** canonical example of **semantic material progression**.  
**Example logic:** charcoal stone → shiny gold → translucent liquid glass → Ethereal.  
**Binding rule:** the lower materials are context-specific; **Ethereal is always the apex**.  
**Do not infer:** the displayed names/APY copy are current product requirements unless separately specified.

### `founder/contextual-3d-icon-family-airbnb-reference.png`
**Authority:** principle/reference for text-adjacent custom 3D object icons.  
**Use for:** polished contextual object imagery, readable silhouette, transparent/backgroundless presentation, warm tangible appeal.  
**Do not infer:** copy Airbnb's objects, exact materials, composition, palette, proportions or identity.
