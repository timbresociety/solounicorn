# Icon rule quick reference

Standard UI icons:
- hyperrealistic outlined 3D image;
- transparent background;
- semantic current-object + nostalgic-object fusion;
- physically believable object-appropriate materials;
- integrated shadow/AO/rim separation;
- readable small silhouette;
- no flat icon, emoji, stock icon, generic 3D, forced rarity material.

Rarity materials are separate. Ethereal is the apex only for rarity-bearing systems.
