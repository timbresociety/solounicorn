# Rarity/progression asset material playbook

## Scope
Only use this system for assets whose job includes communicating explicit progression/rarity: relics, achievements, upgrades, difficulty/rank objects, collectible tiers and comparable states.

Do not apply this material ladder to ordinary navigation/menu/button/header icons.

## Universal rule

**Ethereal is always the apex material state.**

Ethereal = hyperreal iridescent liquid metal: reflective, fluid, materially impossible, premium and transcendent.

Everything below Ethereal is chosen from the semantic evolution of the asset family.

## Method

1. Define what “becoming more rare/powerful/evolved” means for this family.
2. Choose a starting material that communicates the lowest semantic state.
3. Add only as many intermediate materials as the tier count needs.
4. Ensure each step feels directionally more evolved.
5. End at Ethereal.

## Canonical example — enlightenment

```text
charcoal pitch-black stone
→ shiny gold
→ translucent liquid glass
→ Ethereal iridescent liquid metal
```

Meaning:
- stone = raw / dormant / unshaped;
- gold = refined / valuable / disciplined;
- glass = clarified / lucid / purified;
- Ethereal = transcendent / impossible / apex.

This example does **not** make stone, gold or glass mandatory elsewhere.

## Other valid semantic ladders

- machinery: cast iron → brushed steel → polished chrome → Ethereal
- organic: bone/ash → amber/pearl → crystal tissue → Ethereal
- cosmic: dark mineral → stellar metal → astral crystal → Ethereal

Only use these when they actually fit the represented object.

## Reject conditions

- Ethereal used as generic “premium UI” polish;
- gold inserted simply because a tier is rare;
- identical material ladder reused on unrelated asset families without semantic reason;
- CSS rainbow gradient pretending to be Ethereal;
- lower tier visually more luminous/complex than the apex;
- progression readable only by color.
